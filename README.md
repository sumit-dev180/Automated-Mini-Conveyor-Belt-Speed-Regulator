# Automated Mini Conveyor Belt Speed Regulator

## Project Overview
The Automated Mini Conveyor Belt Speed Regulator is an engineering project designed to control the speed of a mini conveyor belt using sensor feedback.

The system uses a DC motor, L298N motor driver and optical proximity sensor to monitor movement and regulate conveyor belt speed.

## Objectives
- Design an automated mini conveyor belt system.
- Control DC motor speed using an L298N motor driver.
- Detect objects and movement using an optical proximity sensor.
- Implement closed-loop speed regulation.
- Maintain the required conveyor transport velocity.

## Components Used
- DC Motor
- L298N Motor Driver
- Optical Proximity Sensor
- Conveyor Belt
- Connecting Wires
- Control System

## Working Principle
1. The DC motor drives the conveyor belt.
2. The optical proximity sensor detects objects or monitors movement.
3. Sensor feedback is used to monitor conveyor operation.
4. The control system adjusts motor speed according to the feedback.
5. The system aims to maintain the desired conveyor belt speed.
